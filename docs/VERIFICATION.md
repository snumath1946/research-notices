## 실패·수정 매니페스트

### 실행 환경 제약
- 실패 증거: `npm test`는 npm 명령 부재. `node --test tests/model.test.cjs`는 자식 프로세스 실행 `spawn EPERM`.
- 추정 원인: 기본 실행 경로와 이 환경의 자식 프로세스 제한.
- 목표 수정: 설치 없이 `node tests/model.test.cjs`로 같은 Node 테스트 하네스를 직접 실행. package.json도 같은 방식으로 수정.
- 예상 효과: 검증 항목을 줄이지 않고 실행 가능.
- 회귀 위험: 테스트 내용 변화 없음. 일반 Node 환경에서도 직접 실행 가능.
- 재검증: 동일 테스트 10개 중 9개 통과, 검색 1개 실제 실패를 발견함.
- 롤백 방법: package.json의 test 스크립트만 이전 명령으로 복원 가능.
