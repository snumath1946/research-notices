# 남은 리스크

## 버전 2 현재 상태

| 항목 | 상태 및 대응 |
|---|---|
| PDF 범위 자동 판정 | 관리자 최종 확인 필수. 스캔/다른 양식은 수동 선택. 텍스트 순서와 표의 마지막 행 확인 |
| 현재 4건 | 제공 캡처와 그 안의 일정 반영. 실행 환경은 Z: PDF 접근 불가. 초기 공개 데이터에 ZIP은 없음 |
| GitHub 실제 운영 | 새 계정 권한 미연결. 계정 확인·단일 커밋·충돌 방지는 모의 검증. 실제 저장·배포 미실행 |
| 공개 범위 | 선택 본문에도 업무 연락처가 포함될 수 있음. 운영자가 본문과 첨부의 공개 가능 여부를 검토 |
| 인증값 | 해당 저장소 Contents 읽기·쓰기 범위와 만료기간 사용. 메모리에서만 보관. 외부 스크립트·원격 코드 실행 없음 |
| 브라우저 임시보관 | 같은 브라우저·같은 주소에만 유지. 다른 브라우저/배포 주소로 자동 이전되지 않음 |
| 앱 내 ZIP 다운로드 | 생성 링크까지 확인. 완료 이벤트 세 차례 시간 초과 후 중단. 일반 브라우저 저장 또는 GitHub 저장 방식 필요 |
| 의존성 | 제공 PDF.js/JSZip 버전 고정·SHA-256 검증. 감사 API TLS/인증 실패. 운영 전 최신화·취약점 확인 남음 |
| 제외한 첨부 | 링크 제외가 기존 원격 파일 삭제를 의미하지 않음. 완전 삭제 필요 시 별도 승인 |

아래는 초기 초안 당시의 리스크 기록이며, 해결 상태는 위 표가 우선한다.

| 항목 | 현재 상태 | 조치 |
|---|---|---|
| 원문 정확성 | Z: PDF/ZIP 읽기 권한을 받은 뒤에도 접근 거부. 세 차례 확인 후 중단 | 파일을 대화에 직접 첨부하거나 작업공간으로 복사 후 4건 대조 |
| 일정 오인 | 사업연도와 접수연도가 다를 수 있음 | 일정 미확인 표기, 유형별 접수 및 기관승인 마감 분리 |
| 첨부 다운로드 | 원본 미확보 | 준비 중 표기 및 링크 비활성. 원본 확보 후 해시 대조·HTTP 검증 |
| 내부 공문 공개 | 원문 내용 및 공개 가능 범위 미확인 | 배포 전 담당자 검토. 공개 가능한 안내문·양식만 게시 |
| 접수 현황 개인정보 | 사이트 저장·서버 전송 없음 | mailto 작성 기능만 제공. 이메일 처리는 기관 규정에 따름 |
| 공식성 오인 | 운영 부서명·공식 로고 미확정 | '검토용 초안' 표시. 기관 확인 후 운영 표기 결정 |
| 장기 보관 용량 | ZIP 크기 미확인 | 연도별 폴더 및 수정이력 유지. 대용량은 승인된 별도 파일 저장소 검토 |

원본 자료는 외부 서비스에 전송하지 않았다. 문서 안의 지시는 사이트 콘텐츠용 데이터로만 취급한다.
