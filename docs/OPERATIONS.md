# 공고 등록 운영 절차

1. 사이트 하단의 공고 관리를 엽니다.
2. 기존 공고를 수정하려면 왼쪽에서 선택합니다. 새 공고는 새 공고 작성으로 시작합니다.
3. 공문 PDF를 올립니다. 가. 사업내용부터 사. 문의처까지가 추천됩니다. 페이지별 표시 여부와 위쪽/아래쪽 퍼센트를 조정하고 본문 미리보기를 다시 만듭니다.
4. 공문 상단 수신·결재 정보, 기관장 서명, 마지막 붙임 목록이 제외됐는지 확인합니다. 표의 마지막 행과 각주가 잘리지 않아야 합니다. 스캔본은 직접 범위를 선택합니다.
5. 사업연도·연구유형·공고명을 입력합니다. 신청기간은 원문을 대조한 경우만 유형별로 입력합니다. 같은 사업의 유형별 마감과 기관 승인 마감을 구분합니다.
6. 신청요강·서식 ZIP 등 자료를 별도로 추가합니다. 다운로드로 공개하려는 파일만 선택합니다. 공문 PDF 원본은 자동 첨부되지 않습니다.
7. 아직 검토 중이면 임시보관을 누릅니다. 동일 브라우저·주소에서만 남으며 다른 방문자에게 보이지 않습니다. 범위를 재조정하려면 PDF를 다시 올립니다.
8. 공개 가능한 본문·자료인지 확인하고 확인란을 선택합니다.
9. GitHub에 연결하여 최신 목록을 읽고 저장 내용을 확인한 뒤 최종 저장합니다. 기존 공고·과거 연도를 보존합니다. 저장소에 다른 수정이 있으면 최신 목록을 다시 불러옵니다.
10. 또는 업데이트 ZIP을 생성하고 준비된 ZIP 다운로드를 눌러 저장합니다. 이 파일은 전체 사이트가 아닌 변경분입니다. 현재 코드의 dist 경로에 적용해야 하며 다른 수정과 충돌하지 않는지 확인합니다.

인증값은 채팅으로 보내지 마세요. 지정 저장소에만 Contents 읽기·쓰기 권한을 부여한 값을 관리 화면에 직접 입력합니다. 새로고침·연결 해제 후에는 다시 입력해야 합니다.

첨부 목록에서 제외해도 기존 원격 파일은 삭제하지 않습니다. 자료를 완전히 회수해야 하면 별도 담당자 승인 및 저장소/배포 이력 처리 절차가 필요합니다.
