# 연구과제 공모 안내 사이트 작업 계획

## 목표·입력·출력
- 목표: 교수 대상 공모 목록, 상세 안내, 첨부 다운로드, 연도별 누적 조회를 제공하는 디자인 초안.
- 입력: 사용자가 제공한 2027년 공고명 4건 및 공통 유의사항. Z: 원문 PDF/ZIP 8개는 접근 거부로 읽지 못함.
- 출력: 외부 의존성 없는 정적 사이트, 데이터 구조, 운영 문서, 자동 검증 및 검토 화면.
- 제외: 공개 배포, GitHub 저장소 생성·커밋·push, 실제 이메일 발송, 접수정보 수집 서버.
- 최소 가정: 2027은 사업연도이며 실제 접수연도·신청기간과 같다고 가정하지 않음. 제목에 없는 지원요건·금액·기간은 미입력.

## 책임 구분
- Delegate: 디자인·구현·익명 샘플 검증·업데이트 절차 작성.
- Review: 디자인, 원문 대비 일정과 신청요건, 첨부자료 공개 가능 범위.
- Own: 기관 명의 사용, 공개 대상, GitHub 저장소·운영 배포 및 개인정보 처리 결정.

## 단계와 완료 기준
1. 자료·스킬 확인: 지정 GitHub 저장소의 두 SKILL.md 확인. 원문 접근 불가 상태 기록.
2. 데이터·검증 기준: 4건 등록, 일정 미확인 상태 보존, 연도별 누적, 이메일 요청 필드, 실제 파일만 다운로드 허용.
3. 구현: 목록·검색·필터·상세·신청안내·반응형·키보드 탐색.
4. 검증: 실제 입력/출력 예시의 모델 테스트, 정적 링크·구조 검증, 브라우저 목록/상세/모바일 확인.
5. 전달: 로컬 초안과 소스 ZIP, 운영 권고. 원문 8개 재제공 후 내용·파일 연결 필요.

## 완료의 한계
디자인 초안은 검증 후 전달할 수 있다. 실제 공고 내용과 다운로드 기능의 완료는 원문 확보 전까지 보류한다.
